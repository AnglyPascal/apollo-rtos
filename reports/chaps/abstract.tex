\begin{center}
    \Large \bfseries Abstract
\end{center}

More than half a century ago, the operating system aboard the Apollo Guidance Computer
(AGC) introduced groundbreaking techniques, using a mere 2 MHz CPU and 4 KB of RAM to
successfully navigate the Moon landing. It pioneered hybrid scheduling, fault-tolerant
execution, and recovery mechanisms---techniques that remain relevant in modern embedded
systems.

This project presents \textbf{Apollo-RTOS}, a real-time operating system for the BBC
\texttt{micro:bit v1}, which reimagines the AGC’s resilient architecture in a
contemporary context. Apollo-RTOS features hybrid cooperative-preemptive scheduling,
dynamic memory allocation, a persistent file system spanning Flash and FRAM, and a
Unix-like shell interface, all within a minimal monolithic kernel. It also implements a
robust recovery mechanism inspired by the AGC’s radical ``\textit{restart everything}''
strategy, supporting up to 16 concurrent processes with integrated automated testing
capabilities.

Apollo-RTOS demonstrates how revisiting historical design principles through the lens
of modern embedded development can yield systems that are robust, extensible, and
highly reliable---even under tight resource constraints.
